# WKL Labs System Master

Date: 2026-06-09 · Author/agent: Codex

## 1. Product Overview

WKL Labs is a Next.js product hub for business tools. The public surface currently includes a home landing page, generated tech-news blog, newsletter/waitlist capture, support/contact paths, metadata routes, and a cron endpoint for AI-assisted blog generation.

## 2. User Roles

- Public visitor: reads landing page and blog, clicks product links, submits email, contacts support.
- Site operator: configures environment variables, runs/deploys cron, monitors blog generation and newsletter capture.

## 4. Core Workflows

- Visitor explores products: home hero -> platforms section -> product card CTA.
- Visitor joins waitlist/newsletter: email form -> `/api/subscribe` -> Resend contact creation.
- Visitor reads blog: `/blog` -> `/blog/[slug]` -> optional original source link.
- Operator generates posts: `/api/cron?secret=...` -> RSS fetch -> Anthropic selection/writing -> Postgres insert.

## 5. Lifecycle / Status Map

- Product status: `live` or `coming-soon` in `src/lib/products.ts:3-13`.
- Blog post lifecycle: generated by cron, inserted into `blog_posts`, rendered by blog routes.
- Email subscription lifecycle: client submit, API validation, Resend contact creation.

## 6. Data Model Map

Verified table creation exists for `blog_posts` with `id`, `title`, `slug`, `summary`, `content`, `source_url`, `source_name`, `category`, `published_at`, and `created_at` (`src/lib/blog.ts:16-31`).

## 7. API & Mutation Risk Map

- `/api/subscribe`: public mutation into Resend audience; validates email but needs env and duplicate handling review (`src/app/api/subscribe/route.ts:7-26`).
- `/api/cron`: secret-protected content mutation into Postgres; uses RSS, Anthropic, and DB writes (`src/app/api/cron/route.ts:26-119`).

## 8. UI/UX System Status

- Dark slate/navy visual system across home and blog.
- Shared navbar and footer are used by home/blog pages.
- Home uses animated `FadeIn` wrappers and fixed action controls.
- Blog uses simple readable list/detail layouts.

## 9. Localization / Currency / Platform Assumptions

- Locale formatting is `en-US` for blog dates (`src/app/blog/page.tsx:9-13`, `src/app/blog/[slug]/page.tsx:19-23`).
- No currency logic is present in this repo.
- Canonical domain is hard-coded as `https://wklapp.com`.

## 10. AI / Automation / Background Jobs

- Anthropic SDK is used in `/api/cron` for story selection and post generation.
- RSS feeds include TechCrunch, The Verge, Ars Technica, and Hacker News.
- Blog page revalidates every 3600 seconds.

## 11. Guardrails

- Treat source as truth over docs.
- Keep UI-only work separate from API/schema/business-logic work.
- Do not deploy, push, or run production cron without explicit approval.
- Confirm product URLs, canonical domain, and env vars before launch.

## 12. Known Risks & Open Questions

- Product links are placeholders in `src/lib/products.ts`.
- Newsletter duplicate handling and missing env behavior need verification.
- Cron duplicate post prevention is weak because slugs include `Date.now()`.
- Dynamic blog metadata and sitemap entries are not yet implemented.
- AI-assisted blog disclosure policy is undecided.
